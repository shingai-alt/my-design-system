Input

component

1行のテキストを入力する部品です。検索特化なら search-input、選択肢からの選択は select、複数行は textarea を使います（いずれも未実装）。

md

enableborder: stroke-control
errorinput-error

使用法

OK

  • ラベルと1対1で対応させ、<label> で関連付ける
  • エラー時は input-error を付け、エラー文言を近くに表示する
  • 必須/任意はラベル側で示す（placeholder に必須表示を書かない）

NG

  • placeholder をラベル代わりにしない
  • 色だけでエラーを伝えない → 文言も併記する
  • 生の border / padding を書かない

必須対応

  • <label> で関連付ける（placeholder はラベルの代わりにならない）
  • エラー時は aria-invalid="true" と aria-describedby でエラー文言に紐付ける
  • :focus-visible で info/600 のフォーカスリング（DS担保）
