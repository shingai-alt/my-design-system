Search Input

component

フリーワード検索の入力です。クリア（×）と送信（検索）を内蔵しています。通常の1行入力は input を使います。

基本形

入力するとクリアボタンが現れる（CSSのみ、:placeholder-shownで検知）

state

error
disabled

使用法

OK

  • type="search"。md/lgでは送信ボタンを出す
  • <form role="search"> で包む

NG

  • 一般のテキスト入力に流用しない → input

必須対応

  • 検索フォームを <form role="search"> で包む
  • 入力欄に可視ラベル か aria-label で名前を付ける
  • クリアボタンに aria-label="クリア"、検索アイコンは aria-hidden="true"
