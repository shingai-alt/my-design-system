Select

component

あらかじめ決まった選択肢から1つを選ぶ、ネイティブ <select> のスタイルです。見た目は Input と揃えています。

size

smh32
md（既定）h40
lgh48

state

md

enableborder: neutral-400
errorselect-error
disabled:disabled

使用法

OK

  • 見た目は input と揃える（サイズ・角丸・枠線を統一）
  • 選択肢が少ない（2〜4件・常に見せたい）場合は radio-group を検討する

NG

  • 独自の見た目のドロップダウンをJSで自作しない → まずネイティブ select を使う
  • 最初の option を「選択してください」のダミーのまま必須項目にしない

必須対応

  • <label> で関連付ける
  • ネイティブ要素なのでキーボード操作・スクリーンリーダー対応は標準で確立している
  • :focus-visible で info/600 のフォーカスリング（DS担保）
