Tab

component

同じ階層にある複数のビューを切り替えるナビゲーションです。ページ遷移を伴いません。

使用法

OK

  • tabs で囲み、各項目に role="tab" + aria-selected を付ける
  • 件数を添えたい時は tab-count を項目内に置く

NG

  • 5個を超えるタブを並べない → select や別のナビゲーションを検討する
  • 現在地の表現を色だけにしない → aria-selected を必ず付ける

必須対応

  • コンテナに role="tablist"、各項目に role="tab" + aria-selected
  • 対応するパネルには role="tabpanel" + aria-labelledby
  • 左右矢印キーでの移動はJS側で実装する
