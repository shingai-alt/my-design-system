Page Shell

component

ページのコンテンツ領域幅を全ページで揃えるためのラッパーです。ヘッダー/フッター/mainそれぞれの内側に置きます。

page（一覧・帯向け）

max-width: var(--container-page) = 1220px

page-shell（このグレー帯の中で最大1220pxに中央寄せ）

page-shell-content（フォーム・設定・詳細向け）

max-width: var(--container-content) = 900px

page-shell page-shell-content（900pxに絞る）

使用法

OK

  • 全幅の帯（header/footer/section）の直下に置き、中身をこの中に入れる
  • フォームや設定・詳細は page-shell に .page-shell-content を併記して900pxに絞る

NG

  • max-w-5xl等のサイズ名でコンテナ幅を新規に書かない
  • page-shellを入れ子にしない → 帯ごとに1つ

必須対応

  • ランドマーク要素（header/nav/main/footer）で領域を構造化する
  • page-shellは帯ごとに1つ（入れ子にしない）。DOM順＝読み上げ順を保つ
