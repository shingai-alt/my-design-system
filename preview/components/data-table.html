Data Table

component

複数レコードを行×列で一覧表示します。Tailwindの table ユーティリティと衝突するため data- 接頭辞にしています。

基本形

契約名取引先金額状態
契約A株式会社サンプル¥1,200,000有効
契約B合同会社テスト¥85,000期限切れ
契約C株式会社デモ¥3,400,000審査中

空状態

項目
データがありません

使用法

OK

  • 状態列には badge を使う
  • 操作列（編集/削除）は行の右端に置く
  • データが0件の時は colspan で結合した空状態メッセージを表示する

NG

  • table要素を手書きスタイリングしない
  • 金額・数値列を左寄せにしない → data-table-num で右寄せに

必須対応

  • <th scope="col"> を見出しセルに付ける
  • ソート可能な列は aria-sort を th に付ける
