Link

component

コンテンツがナビゲーション可能であることを示すインラインリンクです。結果が「移動」なら link、「処理の実行」なら button を使います。

色のバリエーション

本文中にこういう色のリンクを置きます。

別タブで開く場合は外部リンクアイコン付きになります。

補助的なリンクはニュートラル色を使います。

暗い背景の上のリンク

使用法

OK

  • 本文中に置きfont-sizeは周囲からinherit（サイズを固定しない）
  • 別タブは target="_blank" rel="noopener noreferrer" + 外部リンクアイコン

NG

  • 送信などのアクションに link を使わない → button
  • 下線を消さない

必須対応

  • リンク文言だけで目的が分かるようにする（「こちら」「詳細」を避ける）
  • 新規タブは target="_blank"+rel="noopener noreferrer" と、外部/新規タブの手がかりを添える
