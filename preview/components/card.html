Card

component

関連する情報をひとまとまりの区画として提示するコンテナです。border + 背景色で区切り、シャドウは使いません。

header / body / footer

プランA

月額プラン

border + 背景色だけで区切っています。

header/footer無し版

card-bodyだけでも使える。

使用法

OK

  • border + 背景色で区切る（恒常的なsurfaceにシャドウを使わない）
  • card-header / card-body / card-footer で内部を構造化する

NG

  • シャドウで浮き上がりを表現しない → シャドウは modal 等の一時レイヤー専用
  • card内にネストしたcardを重ねない

必須対応

  • カード自体に意味的な役割は無い（見出しは文脈に合った要素を使う）
  • カード全体がリンクの場合は内部に <a> を1つだけ置く
