Design System

Tailwind v4

ホーム > Components > Textarea

Textarea

component

複数行のテキスト入力です。文字数カウンタを付けられます。1行入力は input を使います。

基本形（文字数カウンタ付き）

0/100

state

error
disabled

使用法

OK

  • textarea-control で囲み、必要なら maxlength + textarea-counter を出す

NG

  • 1行入力に使わない → input
  • エラー色を直書きしない → textarea-error を使う

必須対応

  • 可視ラベルを for/id か aria-labelledby で関連付ける（placeholderはラベルにしない）
  • エラー時は aria-invalid="true" + aria-describedby
  • 文字数カウンターは aria-live="polite" で残量・超過を通知
