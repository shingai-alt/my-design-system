Label Control

component

フォーム項目のラベル＋必須/任意バッジ＋サポートテキストのまとまりです。入力欄の直上に置きます。

必須 / 任意バッジ

必須

受信可能なアドレスを入力してください

任意
必須

8文字以上で入力してください

使用法

OK

  • 必須/任意は label-badge-required / label-badge-optional で示す
  • 補足は label-control-support、エラー/補足文は field-error-text / field-support-text を入力欄の直後に置く

NG

  • 必須を色だけで示さない → テキストのバッジを使う
  • 対象フィールドと切り離して遠くに置かない → 直上に置く

必須対応

  • label-control-text を <label for> にして入力欄のidと結ぶ
  • サポート文にidを付け、入力欄のaria-describedbyで参照する
  • 必須はバッジ（視覚）+ 入力欄のrequired（プログラム的）を両方付ける
