Checkbox / Radio

component

Checkboxは複数選択可能なオン/オフの入力、Radioは複数の選択肢から1つだけを選ぶ入力です。

Radio

役割

使用法

OK

  • checkbox-label / radio-label でラップし、テキストをクリック領域に含める
  • radioは同じ name でグループ化し、radio-group でまとめる
  • radioの選択肢は常に2件以上（1件だけならcheckbox）

NG

  • チェックの意味をテキスト無しで色だけに頼らない
  • 選択肢を隠して1つだけ見せる用途にradioを使わない（それはcheckboxの役割）

必須対応

  • <label> でテキストと関連付ける
  • radioグループには fieldset+legend か role="radiogroup" を付ける
  • ネイティブ要素なのでキーボード操作・スクリーンリーダー対応は標準
